# Governance

Clavis is maintained by the project maintainers and open to community
contributions.

## Decisions

- Small changes: pull request review.
- Security-relevant changes: two maintainer approvals and a threat-model note.
- API/breaking changes: public discussion and the deprecation policy in
  [docs/api-stability.md](docs/api-stability.md).
- Roadmap changes: public issue/discussion.

## Maintainers

Maintainers are listed in `CODEOWNERS` and the repository settings. New
maintainers are added after sustained, high-quality contributions and a
security review.

## Funding

See [docs/sustainability.md](docs/sustainability.md). No feature is gated behind
payment.

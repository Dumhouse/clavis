# Sustainability

Clavis is open source under Apache-2.0. The core product is not feature-gated:
self-hosted users get the same security, schema, dynamic-secret, approval, and
agent features as everyone else.

## Funding

- GitHub Sponsors for individuals and companies.
- Open Collective for transparent project expenses.
- Paid support and migration services, optional and separate from the code.
- No proprietary “enterprise-only” security features.

## Spend priorities

1. External security audits and penetration tests.
2. Maintainer time for reviews, releases, and vulnerability response.
3. CI/build infrastructure and reproducible-release verification.
4. Documentation, accessibility, and migration tooling.
5. Community events and contributor stipends.

## Governance

- Roadmap and design discussions happen in public.
- Security reports follow the disclosure policy.
- Financial reports are published for Open Collective.
- No feature is removed from the open-source edition to drive paid upgrades.

# Community

- **GitHub Discussions** — questions, ideas, show-and-tell, and migration help.
- **Discord/Matrix** — real-time help. Invite links are published in the
  repository README once the rooms are live.
- **Security** — never use public channels for vulnerabilities; see
  [vulnerability-disclosure.md](vulnerability-disclosure.md).
- **Roadmap** — [roadmap.md](roadmap.md) and the public GitHub project.

## Contribution paths

- Report bugs with a minimal reproduction.
- Improve docs and migration guides.
- Add importer/sync providers with tests.
- Fuzz targets and accessibility checks are welcome.
- Security fixes follow coordinated disclosure.

Participation is governed by [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).

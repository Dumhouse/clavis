# Welcome to Clavis

This is the community space for Clavis, the open-source secrets manager for
humans, machines, and AI agents.

## Start here

- Docs: https://github.com/dumhouse/clavis/tree/main/docs
- Quickstart: `/docs/quickstart.md`
- Security reports: **never post vulnerabilities here.** Use GitHub Security
  Advisories or dumhousestudio@gmail.com.

## Rooms

- #announcements
- #help
- #development
- #integrations
- #show-and-tell
- #security-announcements (locked; no reports)

## Rules

- Be respectful; follow the Code of Conduct.
- No secret values, tokens, customer data, or private URLs.
- Use threads and include versions/logs with secrets redacted.
- Security issues go private, not to chat.

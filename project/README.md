# Project materials

Planning, launch, and governance material lives here. None of it is shipped in
the binary or served by the docs site.

| Folder | Contents |
|---|---|
| `tasks/` | Milestone task lists (M0–M6) |
| `launch/` | Show HN / Product Hunt / Reddit / dev.to drafts and listings |
| `security/` | External audit scope and secret-scanning partner packet |
| `design/` | Clickable UI mockups |
| `loadtest/` | k6 load tests |

Product documentation lives in [`../docs/`](../docs/), and the website is built
from it with VitePress.

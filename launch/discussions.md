# GitHub Discussions setup

Enable Discussions, then create:

| Category | Format | Purpose |
|---|---|---|
| Announcements | Announcement | Releases, security notes, roadmap changes |
| Q&A | Question and answer | Installation and usage help |
| Ideas | Open-ended discussion | Feature proposals before issues |
| Show and tell | Open-ended discussion | Deployments, integrations, demos |
| Migration help | Question and answer | Infisical/Doppler/Vault/.env moves |
| Security | Announcement | Only non-sensitive security announcements; reports go private |

Pin a welcome post linking:

- quickstart
- security policy
- community code of conduct
- docs site
- demo instructions

Moderation: move support questions to Q&A, convert accepted ideas to issues, and
never allow secret values or customer data in posts.

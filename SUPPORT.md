# Getting help

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/Dumhouse/clavis/discussions). Use
**Q&A** for how-to questions, **Ideas** for feature proposals, and **Show and tell**
to share your setup. Answers there help the next person with the same question.

Before you ask:

- Read the [documentation](https://dumhouse.github.io/clavis/), especially the
  [quickstart](https://dumhouse.github.io/clavis/quickstart) and the
  [CLI reference](https://dumhouse.github.io/clavis/commands).
- Search existing discussions and issues.

## Bugs

Open an [issue](https://github.com/Dumhouse/clavis/issues/new/choose) with the
bug report form. Include the Clavis version (`clavis version`), how you run it
(Docker, binary, Kubernetes), and the smallest steps that reproduce the problem.
**Never paste secret values, tokens or customer data.**

## Security vulnerabilities

Do not open a public issue or discussion. Report privately through
[GitHub Security Advisories](https://github.com/Dumhouse/clavis/security/advisories/new)
or email dumhousestudio@gmail.com. See the [security policy](SECURITY.md).

## What to expect

Clavis is maintained by a small team. We aim to answer discussions and triage
issues within a few days, but there is no guaranteed response time or support
contract.
